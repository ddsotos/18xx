## 3. 確認済みの採用条件

- 初期対象は4人ロング、12小会社、各275、6サイクル。
- ショートで除く4社はAdaptive、Overnight、Bridging、Spacious。
  Expansiveをこの4社に含めない。ロングでは12社すべて実装する。
- 4人以上用の追加3列車・6列車を含める。ショートの各種類削減はしない。
- 通常小会社の列車保持上限は黄色/緑2、紫/灰1。Spaciousは+1。
- 先行購入は初回運営時、山/プールから会社資金で1台。他社取引は通常購入。
- 40%社長の配当は総配当40なら16。会社自身の保有株にも配当する。
- マップ33枚、首都プロジェクト3枚、線路タイル合計135という集計だけでは、
  各形状・各種類の枚数や固定盤面の妥当性までは確定しない。

## 4. 未確定事項と解消条件

| ID | 未確定内容 | 必要な証拠・判定 | 作業/ゲート |
|---|---|---|---|
| U01 | 解決：4人ロングは2×7、3×6、4×4、5×3、6×3、7/∞×7 | 第2版紙面p.3の各スタックを計数し30枚と一致。p.7に従い4人用追加3/6を保持 | GameDataとspecへ反映済み |
| U02 | 線路タイル各ID/枚数/特殊形状 | 部品ごとの台帳、図/実物照合、合計一致 | W01、敷設受入前 |
| U03 | 固定マップ全配置・ホーム・遠隔地値 | 正式構成と配置規則の照合、完全manifest | W01/W03 |
| U04 | 最終サイクルのMR・輸出・終局の厳密な順 | pp.18〜19から逐次手順と期待状態を固定 | W01/W07 |
| U05 | Resourcefulの追加運行を使わない場合の期限 | 能力文/FAQのタイミングを明記 | W01/W06 |
| U06 | ResourcefulとExpress等の組合せ | 対象となるowned trainと廃車保持状態の解釈 | W01/W06 |
| U07 | 同点終局時の「最も早い会社」の境界 | 合併・閉鎖後を含む公式タイブレーク確認 | W01/W07 |
| U08 | 六方向座標と印刷部品の向き対応 | 描画実測と既知配置の辺照合 | W03、固定盤面受入前 |

最終サイクルには次SRがないため輸出しない、という案はU04の確認対象。
通常サイクルの「次SR前の輸出」からの推論を、公式で確定した処理順と混同しない。
不明点は安全側の仮値で本番実装せず、該当受入を止める。
必要な資料が揃う前にも、独立した基盤・保存・人工状態の単体検証は進められる。
