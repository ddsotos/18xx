# 友人向けアクセス手順

この手順は、Cloudflare Tunnel と Cloudflare Access 設定後に、参加者へ共有するための短い案内。

## 参加に必要なもの

- ブラウザ
- 主催者に伝えたメールアドレス

VPN クライアントや Docker は不要。

## アクセス手順

1. 主催者から共有された URL を開く。
2. Cloudflare Access の認証画面が出たら、自分のメールアドレスを入力する。
3. メールに届いた認証リンクまたはコードでログインする。
4. 18xx の画面が表示されたら、通常どおりログインまたはアカウント作成を行う。

## 入れないとき

Cloudflare Access で拒否される場合は、主催者に次を伝える。

- 入力したメールアドレス
- 表示されたエラー文
- URL を開いた日時

18xx の画面が白い、読み込みが長い、途中で止まる場合は、一度ブラウザを更新する。初回起動直後は主催者側で JavaScript assets のコンパイルが走り、表示まで時間がかかることがある。

## 注意

共有 URL は参加者以外へ転送しない。

Cloudflare の認証を通った後でも、18xx 側のログイン情報は別に管理される。
