# 友人向けアクセス手順

この手順は、Cloudflare Quick Tunnel の URL を参加者へ共有するための短い案内。

## 参加に必要なもの

- ブラウザ
- 主催者から共有された `https://...trycloudflare.com` の URL

VPN クライアント、Docker、Cloudflare アカウントは不要。

## アクセス手順

1. 主催者から共有された URL を開く。
2. Login 画面を開く。
3. 初回は `Friend Login` に User Name と Email を入力する。
4. 18xx の画面が表示されたら、主催者から指定されたゲームに参加する。

## 次回も同じユーザーで入る

次回以降は、同じ Email だけで同じユーザーとしてログインできる。User Name は空でよい。

未登録の Email で入る場合は、User Name も入力する。

未登録の Email で既存の User Name を使うとログインできない。

## URL が変わったとき

Quick Tunnel の URL は、主催者がトンネルを起動し直すたびに変わる。

前回の URL が開けない場合は、主催者から新しい `trycloudflare.com` URL を受け取って開き直す。

URL が変わっても、ゲーム状態が主催者側の DB に残っていれば続きから再開できる。

## 入れないとき

主催者に次を伝える。

- 開こうとした URL
- 表示されたエラー文
- URL を開いた日時

18xx の画面が白い、読み込みが長い、途中で止まる場合は、一度ブラウザを更新する。初回起動直後は主催者側で JavaScript assets のコンパイルが走り、表示まで時間がかかることがある。

## 注意

共有 URL は参加者以外へ転送しない。

Quick Tunnel では、URL を知っている人はアクセスできる前提になる。

18xx 側のログイン情報は、Cloudflare とは別に管理される。

この身内用環境では、18xx 側のパスワード入力は不要。
